Two key confirmation

Anything that removes or overwrites something asks for two keys held at once and then a full slide. This page explains every state of that confirmation.

When it fails

  • One key released early: the slider locks again and returns to the start. Nothing ran.
  • Slider released before the end: it springs back. Nothing ran.
  • The job fails after confirming: the full-screen failure result shows the exit code and the last output.

Security

The confirmation is drawn by the app itself. It is not a web page and not an outside service, so it works offline and cannot be skipped by a shortcut, a search result or a script.

How it was checked

The end to end run drives every state: untouched, one key, both keys, part slide, full slide, Escape and Emergency exit.
