Build

On a fresh Windows installation, one command gets everything, builds the app and starts it:

.\build.bat --run

What it does, in order:

  1. Fetches the pinned tools it needs into your user folder and checks each one against its recorded hash
  2. Builds the Chocolatey CLI and the app
  3. Checks that what it built matches the source you have
  4. Starts the app, and only if every step before it succeeded
FlagEffect
--runStart the app after a successful build
--silent, /s, SILENT=1No questions. Stops with a non-zero exit code at the first real failure.

An interrupted run can simply be started again. Half-fetched tools are never used.
