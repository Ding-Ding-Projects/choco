Pins

What it does

A pinned package is skipped by upgrades until it is unpinned.

Settings

"Ignore pinned" on Updates. Default: on.

How it fails

Pinning on an offline machine is queued. A read only agent refuses and says so.

Security

Needs the Operator role.

How it was checked

Unit checks for the command line, and the end to end run pins and unpins git.
