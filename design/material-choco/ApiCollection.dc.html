POST /api/jobs

Queues one Chocolatey command on one or more machines. Needs the Operator role.

Request

POST [HUB ADDRESS]/api/jobs
Cookie: session=[SESSION]
Content-Type: application/json

{
  "machines": ["m_7f3a"],
  "command": "upgrade",
  "args": ["git", "--yes"]
}

Answers

StatusMeaning
201Queued. The body holds the job id.
400The command or an option is not in the command schema
403Your role may not run commands, or the machine allows only some commands
409A destructive command was sent without its confirmation

The master collection material-choco.postman_collection.json holds every request on the left and is generated from the route table, so it cannot miss one.
