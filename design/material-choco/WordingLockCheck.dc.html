Wording lock check

Runs at the start of every build and before every push. It proves that the build machine holds the current wording dictionary. Neither the dictionary nor its fingerprint is stored in this repository.

build.bat
> build.bat --silent
[0/4] wording lock   ok
      Dictionary found. Its fingerprint matches the expected value kept beside it.
[1/4] dependencies   ok
[2/4] chocolatey cli ok
Lock is current
Nothing to do
