# Focus modes

Five separate switches that reduce what is on screen or add gentle structure. All are off by default.

## What it is

| Mode | Effect |
| --- | --- |
| Focus | Collapses the tab strip to icons and hides the Overview banner |
| Low stimulation | Turns off movement, mutes colour, silences sounds, and replaces full-screen install results with notifications |
| Time awareness | Shows a clock in the top bar and the elapsed time on running jobs |
| One thing at a time | Pages show one machine at a time: the first one selected |
| Momentum | After a job finishes, the notification offers the next logical step |

## How to use it

**Settings**, **Focus modes**. Each switch is independent and also reachable from the command palette, where it can be flipped in place.

## What was checked

No dedicated named check. Each mode is a small layout or behaviour rule in the interface source.

## Known limits

- The modes are simple forms of each idea.
- How they combine with [school mode](school-mode.md) is not documented beyond this page: they are independent settings and both apply.
