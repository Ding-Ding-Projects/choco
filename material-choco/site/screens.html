Real screens

49 captures of the running app, grouped by what they show. A test stand-in played the part of choco.exe.

Captured from the running hub and agents by the project's end to end run, not drawn. In that run a small test stand-in played the part of choco.exe, because the capture machine runs Linux, so package names and versions in the pictures come from the stand-in. The red notification in several captures is left over from a command that was made to fail on purpose earlier in the same run. Select a picture to enlarge it and read its description; the arrow keys move between pictures and Escape closes the viewer.
