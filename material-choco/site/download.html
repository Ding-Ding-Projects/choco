What the installer contains

The app

The desktop shell and the interface, with its own runtime. Nothing else has to be installed first.

The Chocolatey CLI

A choco.exe built from this repository by the release workflow. On first use the app copies it to a folder it owns and leaves any Chocolatey you installed yourself alone.

The agent

The same program can connect the PC to a hub, with or without a window: MaterialChoco.exe --agent run.

A Squirrel.Windows package

Setup.exe installs for the current user and creates the shortcuts. The release also carries RELEASES and the full .nupkg.

Checking what you downloaded

There is no signature to verify, so these are the checks that exist:

  • Take the file from the releases page of Ding-Ding-Projects/choco, from a release whose tag starts with material-choco-v. The button above links straight to that file.
  • Compare the file name and size with the ones shown above.
  • GitHub records a SHA-256 digest for each release file. When the lookup above succeeds and GitHub provides it, the digest of the newest installer is shown here.
  • Compute the digest of your download in PowerShell and compare:
Get-FileHash .\Setup.exe -Algorithm SHA256

A matching digest shows that the file is the one GitHub holds. It does not show who built it; only a signature could, and there is none.

Hub image
