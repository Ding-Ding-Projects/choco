Features

61 features ship in this build. Each has its own page: what it is, how to use it, what was checked and how, and its known limits. Planned work is in the roadmap, not here.

Packages

14 features

  • Bundled Chocolatey CLIThe Chocolatey CLI built from this repository ships inside the app, so there is nothing to install before the first command.
  • Command schema generated from the CLI sourceEvery command, option, config setting and feature the app offers is read from the C# source of the CLI in this repository, not typed in by hand.
  • ConsoleOne page that offers every Chocolatey command with every one of its options, as a form.
  • Command preview and dry runEvery form shows the exact command before it runs, and the option dialogs can run it as a dry run first.
  • Installed packagesA list of the packages on each machine, with status, single actions, bulk actions, and packages.config export and import.
  • Discover and installSearch the package sources of a machine and install from the results, with a single click or with every install option.
  • UpdatesWhat is out of date on each machine, and one button to upgrade it all.
  • SourcesThe package sources of each machine, with a switch to enable or disable each one.
  • Config and featuresEvery Chocolatey config setting and every feature switch, per machine, with the description from the CLI source.
  • PinsHold a package at its current version so that upgrades skip it.
  • API keysSee which sources have a stored API key on a machine, add one, or remove one, without the key value ever being shown.
  • Cache, templates, rules, licence and supportA page of small readers for the remaining CLI commands.
  • Package builderForms for the commands that create and publish packages: new, pack, push and export.
  • Bulk actions and exportsTick several rows and act on all of them, or export a list as CSV, JSON or Markdown.

Remote management

18 features

  • HubA web app that manages many Windows machines from one place.
  • Hub container imageThe hub as a container image with a volume for its data, a health check and a non-root user.
  • Sign inSign in to the hub with a password or a passkey, with lockout after failures, and sessions that expire.
  • PasskeysSign in to the hub with a fingerprint, a face, a device PIN or a security key.
  • Users and rolesMore than one person can sign in to a hub, each with a role: admin, operator or viewer.
  • PairingA one time code joins a Windows machine to a hub.
  • Remote agentThe part of the app that connects a Windows machine to a hub, runs the jobs it is given, and streams the output back.
  • Read only agentsA machine can be paired so that it reports everything and changes nothing.
  • Command allow listsLimit a machine to a chosen set of Chocolatey commands, enforced by the hub and, when set on the machine, by the agent itself.
  • Machine selection and groupsChoose which machines the pages show and act on, and label machines with groups.
  • Jobs and live outputEvery command becomes a job with a state, live output, an exit code and a log you can export.
  • Offline job queueA command for a machine that is switched off waits for it, for up to 7 days.
  • SchedulesRun a command every day, or on chosen days of the week, on all machines, a group, or a chosen set.
  • HistoryAn append-only record of who did what on the hub, with export.
  • Status webhooksThe hub posts a short message to an address of your choice when a job fails, a machine stays offline, or sign in is locked out.
  • Secret maskingSource passwords and API keys are replaced with ******** wherever a command is recorded or displayed.
  • Secrets at restThe hub encrypts the secret values it has to keep on disk, and is plain about what that does and does not protect.
  • Hub HTTP APIThe JSON API that the interface and the agents use, documented with a Postman collection.

Safety and feedback

4 features

  • Two key confirmationDestructive actions need two separate keys and then a slider before they run.
  • Install result takeoversEvery install or upgrade that finishes takes over the screen: a celebration on success, an alarm with the exit code and the last output on failure.
  • NotificationsShort messages that do not block your work, and a list of them behind the bell.
  • Loading, empty, offline and error statesEvery page says what is actually true: loading, nothing here yet, offline, or failed and why.

Interface

12 features

  • OverviewThe first page: what needs attention across the selected machines, and one button to upgrade everything.
  • First-run wizardA four step setup that does real work on the first start, and can be skipped.
  • Command palettePress Ctrl+Shift+F anywhere to search every page, command and setting, and act on the result.
  • Keyboard shortcutsOne list of shortcuts that the key handler, the menus, the command palette and the Help page all read, so a shortcut that is shown is the shortcut that works.
  • TabsEvery page is a tab in a strip on the left.
  • Context menus with a filterRight click anything for its actions.
  • Filters and regexA foldable filter bar on every list, with plain text by default and regular expressions on request.
  • Pattern builderDescribe the text you are looking for, and the builder writes the regular expression.
  • Settings that explain themselvesEach setting says what it does and whether its value is the built-in default, and can be reset on its own.
  • Changelog viewerThe changes of each version, inside the app, with a filter and an export.
  • Help pageHelp that works offline: short articles, the keyboard shortcuts, and the help text of every Chocolatey command.
  • Phone layoutThe hub's interface works at phone width, so you can check on machines and start an upgrade from a phone.

Built-in tools

1 features

  • Base64 toolsTurn text or a file into Base64 and back, entirely in the browser.

Language, look and comfort

9 features

  • Language modesEnglish, Hong Kong Cantonese, or both at once, with a separate tone setting for each language.
  • Personal wording fileLoad a JSON file that replaces words in the interface with your own, kept on your device.
  • School modeA plain mode for shared or public screens: English only, no playful options, with an optional PIN.
  • Theme and seed colourLight and dark themes, both derived from one seed colour that you can change.
  • Custom logo and presetsPut your own mark in the top bar, and apply a named set of appearance settings with one click and an undo.
  • Timed settingsLet settings switch by the clock: a dark theme in the evening, quieter results at night.
  • Accessibility toolsText size, contrast, motion, target size and focus ring, one click from every page.
  • Sound and narrationShort action sounds, and an optional voice that reads job results aloud.
  • Focus modesFive separate switches that reduce what is on screen or add gentle structure.

Desktop app and delivery

3 features

  • Desktop appA Windows app that manages Chocolatey on the PC it runs on, and can also connect that PC to a hub.
  • Windows installerA Squirrel.Windows Setup.exe, built by the release workflow with the repository's own Chocolatey CLI inside.
  • Version and build timeThe version and the build time of the running copy are on the first screen and on every page.
