Keyboard shortcuts

One list of shortcuts that the key handler, the menus, the command palette and the Help page all read, so a shortcut that is shown is the shortcut that works.

On this page
  1. What it is
  2. How to use it
  3. What was checked
  4. Known limits

What it is

KeysAction
Ctrl+Shift+FOpen the command palette
Ctrl+Shift+UGo to Updates
Ctrl+Shift+JGo to Jobs
Ctrl+Shift+MGo to Machines
Ctrl+Shift+HGo to History
Ctrl+Shift+SGo to Settings
F1Open Help
Ctrl+Shift+AOpen accessibility tools
Ctrl+Shift+ERefresh the inventory of the selected machines
Ctrl+Shift+LOpen notifications
Alt+PageDown, Alt+PageUpGo to the next or previous open tab
/Focus the filter of the current page, when not typing
Alt+ArrowUp, Alt+ArrowDownMove the focused tab up or down in the tab strip
Shift+F10Open the context menu of the focused element
EscapeClose the open dialog or menu

This table is copied from ui/js/keys.js. If the two ever differ, the file is right.

How to use it

Press the keys. The Help page lists them, menus show them beside the matching item, and the palette finds them by name.

What was checked

End to end checks Ctrl+Shift+M goes to Machines, menus show the shortcuts that are registered, help lists every keyboard shortcut and Ctrl+Shift+F opens the palette and filters.

Known limits

  • Shortcuts cannot be changed.
  • Some combinations are also browser shortcuts in some browsers, where the browser may win. In the desktop app there is no such conflict.
  • Global shortcuts work after sign in.

Source of this page: docs/features/keyboard-shortcuts.md. It describes version 0.1 of the app. See the status page for what has and has not been proven.
