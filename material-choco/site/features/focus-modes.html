Focus modes

Five separate switches that reduce what is on screen or add gentle structure. All are off by default.

On this page
  1. What it is
  2. How to use it
  3. What was checked
  4. Known limits

What it is

ModeEffect
FocusCollapses the tab strip to icons and hides the Overview banner
Low stimulationTurns off movement, mutes colour, silences sounds, and replaces full-screen install results with notifications
Time awarenessShows a clock in the top bar and the elapsed time on running jobs
One thing at a timePages show one machine at a time: the first one selected
MomentumAfter a job finishes, the notification offers the next logical step

How to use it

Settings, Focus modes. Each switch is independent and also reachable from the command palette, where it can be flipped in place.

What was checked

No dedicated named check. Each mode is a small layout or behaviour rule in the interface source.

Known limits

  • The modes are simple forms of each idea.
  • How they combine with school mode is not documented beyond this page: they are independent settings and both apply.

Source of this page: docs/features/focus-modes.md. It describes version 0.1 of the app. See the honest status for what has and has not been proven.
