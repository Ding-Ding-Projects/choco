Help page

Help that works offline: short articles, the keyboard shortcuts, and the help text of every Chocolatey command.

On this page
  1. What it is
  2. How to use it
  3. What was checked
  4. Known limits

What it is

The Help page lists short articles about the app (getting started, pairing, security, filters and the pattern builder, tabs, menus, bulk actions and exports, the built-in tools, timed settings and more), a table of keyboard shortcuts, and one entry per Chocolatey command with the description and options from the CLI source. Everything ships with the app, so it needs no network.

How to use it

Open Help, or press F1, and type in the search field; matching entries open. The field has a Regex switch. Open all and Close all unfold and fold every entry, and the shortcut list can be exported.

What was checked

End to end checks help lists every keyboard shortcut and help has offline articles for the new tools.

Known limits

  • The in-app articles are short. The fuller guides are on the project site.
  • Command help text comes from the CLI source and is English.
