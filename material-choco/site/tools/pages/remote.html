Three steps

  1. Start the hub.One container, reachable on your network. It keeps its data in a volume. The first visit creates the administrator; there is no default account.
    docker run -d -p 8080:8080 -v material-choco-data:/data ghcr.io/ding-ding-projects/material-choco-hub:latest
    Guide: running the hub in a container
    {{frame:01-first-run-create-administrator.png}}
  2. Create a pairing code.On the Machines page. It works once and expires after 10 minutes. Turn on read only first if the machine should refuse changes.Feature: pairing
    {{frame:04-machines-pairing-code.png}}
  3. Enter it on the Windows machine.In the app, or on a server without a desktop session:
    MaterialChoco.exe --agent enroll --hub https://your-hub --code XXXX-XXXX
MaterialChoco.exe --agent run
    Guide: pairing and remote agents
    {{frame:05-machines.png}}

Treat hub access as administrator access. The hub can install software with administrator rights on every paired machine. Serve it over HTTPS. Agents refuse plain HTTP to a remote hub unless you opt in for a trusted LAN. Read the security model before exposing a hub.

What the hub gives you

{{thumb:41-users-and-roles.png}}

Users and roles

Admin, operator and viewer. The hub checks the role on every request.

Users and roles {{thumb:44-sign-in-with-passkey.png}}

Passkeys

Sign in with a fingerprint, a face, a PIN or a security key. The password stays as the fallback. Checked with a software passkey device only.

Passkeys {{thumb:40-machine-allowed-commands.png}}

Allowed commands

Limit a machine to a list of commands. The agent can enforce its own list by itself.

Command allow lists {{thumb:42-status-webhooks.png}}

Status webhooks

A short message when a job fails, a machine stays offline or sign in is locked out. Job output is never sent.

Status webhooks {{thumb:12-job-failed.png}}

Jobs with live output

Every command is a job with a state, live output, an exit code and a log.

Jobs {{thumb:18-history.png}}

History

An append-only record of who did what, with export.
