What it does

Every command, every option

23 commands and 190 options, read straight from the CLI source in the same repository. When the CLI gains an option, the app gains a control.

Nothing to install first

The installer carries its own runtime and a Chocolatey CLI built from the repository. One download, one click.

A fleet, not just a PC

Pair machines to a hub with a one time code. Run a command on one, some or all of them. Offline machines get the job when they return.

Hard to break by accident

Uninstalls and removals need two keys and a slider. A read only agent refuses every change, and enforces that itself.

You see what will run

Every form shows the exact command before it runs, with a dry run button. Passwords and API keys are masked in logs.

Loud when it matters

Every install that finishes takes over the screen: a celebration on success, an alarm with the exit code and output on failure.

Remote management in three steps

  1. Start the hub.One container, reachable on your network.
    docker run -d -p 8080:8080 -v material-choco-data:/data ghcr.io/ding-ding-projects/material-choco-hub:latest
  2. Create a pairing code.Open the hub, create the administrator, then make a code on the Machines page. It works once and expires in 10 minutes.
  3. Enter it on the Windows machine.In the app, or on a server without a desktop:
    MaterialChoco.exe --agent enroll --hub https://your-hub --code XXXX-XXXX
MaterialChoco.exe --agent run

Treat hub access as administrator access. The hub can install software with administrator rights on every paired machine. Serve it over HTTPS. Agents refuse plain HTTP to a remote hub unless you opt in for a trusted LAN.
